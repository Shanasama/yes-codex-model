# 旧网页工坊（已归档）

这里放的是以前的浏览器版皮肤工坊，现在不维护了，留着当参考。

- `web/`：旧的单页界面（index.html / app.js / styles.css）
- `start_studio.ps1`：以前用来起本地服务并打开浏览器
- `qa-visual-check.mjs`：以前用 Playwright 跑网页版视觉检查的脚本

现在改皮肤请用 `启动皮肤工坊.cmd` 打开的原生窗口（`dist\studio\SkinStudio.exe`）。
原生窗口是独立的 exe，不需要浏览器。

这份归档里的脚本不能直接用：它们引用的 `plugins\codex-skin-engine\web` 已经不在插件
目录里，本机引擎也只剩 API、不再提供网页静态文件。
