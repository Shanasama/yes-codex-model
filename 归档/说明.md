# 归档说明

这个目录放的是**已经退役、不再维护**的东西，留着只当参考。它们不参与任何安装流程 ——
一键启动、AI 自动安装、插件和皮肤工坊都不会读这里，删掉也不影响任何功能。

目前里面只有一份：

- `旧网页工坊\`：以前的浏览器版皮肤工坊，包含旧的单页界面（`web\index.html`、
  `app.js`、`styles.css`）、当年用来起本地服务并打开浏览器的 `start_studio.ps1`，以及
  旧的网页视觉检查脚本 `qa-visual-check.mjs`。

它为什么不能直接跑了：脚本引用的 `plugins\codex-skin-engine\web` 已经从插件里移除，
现在的引擎只提供 API，不再吐网页静态文件。改皮肤请用 `启动皮肤工坊.cmd` 打开的原生窗口
（`dist\studio\SkinStudio.exe`），那是独立的 exe，不需要浏览器。

留着的原因：想回看旧界面、或者做实现对比时有个参照。哪天嫌碍事，整个 `归档\` 直接删掉
就行，唯一的变化是这个参考没了。

## English

This folder holds retired, unmaintained leftovers kept only for reference. Nothing here is
part of any install path: the one-click launcher, the AI install flow, the plugin and the
skin studio never read it, and deleting the whole folder breaks nothing.

`旧网页工坊\` is the old browser-based studio: the single-page UI, the script that used to
start its local server, and the old visual-check script. It cannot run as-is any more
because the `plugins\codex-skin-engine\web` files it referenced were removed from the
plugin, and the engine now serves only its API, not web assets. Use `启动皮肤工坊.cmd`
(the native `dist\studio\SkinStudio.exe`) to edit skins instead.

It is kept so that the old UI and its implementation stay available for reference. Delete
the folder whenever it gets in the way; the only thing lost is that reference.
